# One Sound Per Event
Part of [[08 Sound-Visual Sync]].

## Rules
- A tick per typed letter, a thump per line drawn. Sounds follow the drawing, not only the beat.
- Drop the music for the most important mark so small sounds stand out (OpenAI Refreshed).
