# Legible 3D Type

Source: Reddit r/MotionDesign word flowers (1 Nov 2026, 403 points in 4 days), via FrameCall write-up

Rules: each petal owns a fixed run of words and drops from the tip when edge-on; text pointing left is set from the other end so nothing reads backwards; words behind another petal hide whole. Never paint words on a turning surface as a texture.
