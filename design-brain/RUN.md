# RUN: the daily 10 AM design run
1. Read [[00 Core]], [[Problems]] and the last 3 entries of [[Daily Log]].
2. Research the web for 2-4 new findings (minimum 2, aim for 4): one aimed at the oldest open item in [[Problems]], the rest from fresh creator edits, motion trends or code tools. Skip anything already in a node.
3. File each finding as a new sub-ball note under its ball, or as a new rule in an existing node, with at least 2 [[links]] to other nodes and a source line in [[Sources]].
4. Look for a new pattern across today's findings and existing nodes; add it to [[Patterns]]. Add any new conflict to [[Problems]]; tick items that got resolved.
5. Build the day's drop at launch-film grade, never basic (Aryan rejected a plain mock on Nov 27): 2-4 polished 9:16 canvas or WebGL motion pieces, each a pure function of time so it can render in Remotion, using Aryan's own lines and real numbers (never invented stats), no fake people. Under each: where the move was stolen from, why it stops a thumb, how to build it with exact timings. Add 2-3 real references to study. Republish to the same artifact link: https://claude.ai/artifact/RKNTVK4SDnjiVYLwb5iARU
6. Append today's entry to [[Daily Log]].
Keep it lean: no full-page dumps, short notes, one preview file.
