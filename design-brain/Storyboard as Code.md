# Storyboard as Code

Source: X, @emilwidlund thread (27 Oct 2026), via randomaccessmemory.cc summary

Launch films built with no After Effects: one TypeScript storyboard file lists scenes as data, GSAP animates DOM with the brand easing, Playwright steps frames into ffmpeg at 60 fps. Directed through Claude Code with taste notes ("no whooshes"). 1:30 film = ~2 h + ~60 prompts, renders in ~6 min. Use: Aryan's reels as a cue file in the repo; changes are one line.
